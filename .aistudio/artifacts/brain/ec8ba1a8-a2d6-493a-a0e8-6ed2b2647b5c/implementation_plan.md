# 霓虹钱塘：杭州江南风格招牌改造与全界面中文化方案

将整座 3D 赛博都市从原有的日式街区全面重塑为**“杭州江南赛博风（霓虹钱塘）”**，把所有街头霓虹灯牌、灯箱匾额、纸灯笼、全息投影、交通路牌替换为极具杭州与江南水乡韵味的中文招牌，并将全部游戏 HUD、主菜单、设置面板、区域地名与委托任务彻底汉化。

---

## 用户确认与关键决策

> [!IMPORTANT]
> 以下为根据您的偏好确立的核心设计方向，确认后即可开始实施：

- **城市美学定位（已确认）**：**杭州江南赛博风格**——融合西湖、河坊街、南宋御街、武林夜市、拱宸桥大运河的江南商铺底蕴与 2077 赛博霓虹光影。
- **招牌排版形式（默认推荐）**：**简体中文与江南传统牌匾书法混排**，辅以少量精炼的赛博英文/拼音副标（如 `LONGJING TEA · 西湖龙井`、`PIAN ER CHUAN · 老杭州面馆`），兼具江南市井烟火气与未来都市感。
- **世界观与全界面本地化（默认推荐）**：游戏主标题定名为 **《霓虹钱塘》**，同步将六大街区、五项联络人委托任务、HUD 仪表盘、小地图方位及设置抽屉全面转化为中文。

## 1. 核心概念与整体概览

- **改造目标**：在不损失任何 WebGPU/Three.js 霓虹发光、雨夜地面反射与动态闪烁着色器效果的前提下，将城市中的所有视觉文字载体（竖向霓虹灯牌、横向门头匾额、方形彩色灯箱、楼顶巨型发光字、纸灯笼题字、街道指路牌、空中全息圆环）替换为杭州江南名店与市井风物，并提供全中文交互界面。
- **目标体验**：玩家漫步在樱花/桃柳掩映的运河步道、拾级而上的河坊灯笼古巷与霓虹闪烁的延安路大道时，所见之处皆是“西湖龙井”、“片儿川”、“知味小笼”、“定胜糕”、“江南丝绸”、“钱塘茶楼”、“听雨轩评弹”等纯正杭城招牌。

## 2. 用户体验与视觉设计

### A. 杭州江南招牌体系设计

1. **竖向与横向霓虹灯牌（Neon Blades & Tube Signs）**
   - **餐饮名吃**：`片儿川`、`西湖醋鱼`、`龙井虾仁`、`东坡肉`、`知味小笼`、`葱包桧`、`定胜糕`、`桂花藕粉`、`杭帮菜`、`老鸭煲`
   - **茶楼酒肆与夜生活**：`西湖龙井`、`钱塘茶馆`、`太和酒家`、`江南小酒馆`、`运河夜肆`、`听雨茶社`、`醉西湖`、`曲院风荷`
   - **江南风物与赛博商铺**：`杭罗丝绸`、`西泠印社`、`张小泉剪刀`、`王星记扇庄`、`南宋御街`、`武林网咖`、`灵隐算命`、`雷峰古玩`、`义体诊所`、`赛博茶寮`
2. **门头彩色灯箱与多层商铺水牌（Color Lightboxes & Fascia）**
   - 采用江南朱砂红、宣纸米白、竹叶青、泥金与靛青配色，绘制带印章纹饰的横向门头（如 `老杭州面馆 · 片儿川`、`湖滨茶庄 · 明前龙井`、`知味楼 · 江南点心`、`回春堂 · 国医馆`、`钱塘绸庄 · 绫罗绸缎`）。
   - 将原本带有日文的方形灯箱与招贴海报升级为 Canvas 实时绘制的**江南国潮灯箱与水乡赛博海报**（西湖游船、龙井新茶、江南评弹、运河夜市等）。
3. **楼顶巨型发光字与天际线地标（Rooftop Channel Letters & Holograms）**
   - 楼顶大字替换为：`钱塘科技`、`西子云端`、`雷峰重工`、`武林广场`、`江南造物`、`杭州二零七七`、`未来钱塘`。
   - 十字路口上空的旋转全息字环更新为：`◆ 欢迎来到 霓虹钱塘 ◆ 西湖烟雨 · 赛博江南 ◆ 钱塘科技 ◆`。
4. **灯笼与市政交通标识（Lanterns & Street Signs）**
   - 河坊巷与沿街悬挂的红灯笼、岸边地灯题字更换为：`茶`、`酒`、`面`、`杭`、`西湖`、`钱塘`、`御街`、`龙井`、`小笼`、`迎客`。
   - 路侧交通标志与巨型蓝底指路牌更换为中国标准样式：指路牌指向 `西湖景区 / Xihu Lake`、`拱宸桥 / Gongchen Bridge`、`武林门 / Wulin Square`；停车牌更新为 `P 停车场 / 空位`；让行牌更新为 `慢 / 让行`。

### B. 全中文界面（UI & HUD）与字体层级

- **视觉与色彩规范**：保持 3D 视口中央 100% 无遮挡，HUD 采用深黑磨砂半透明底衬搭配青玉色（`#00f0ff`）、桂花金（`#ffe23a`）与朱砂红（`#ff3b4e`）点缀。
- **中文字体适配**：在 Canvas 纹理图集与 CSS 界面中引入高质量中文字体栈（`"PingFang SC"`, `"Microsoft YaHei"`, `"Noto Sans SC"`, `"Kaiti SC"`, `"STKaiti"`, `"Songti SC"`），让现代霓虹黑体与传统牌匾楷书/宋体交相辉映。
- **界面模块全汉化**：
  - **开场主界面**：主标题《霓虹钱塘》，副标题“杭州江南 · 二零七七”，按钮“[ 漫步钱塘街区 ]”与“[ 本地 Blender / 雷火 Tripo 3D 工坊 ]”。
  - **左上角街区与时间状态栏**：显示节气/时段（子夜、黎明、清晨、正午、午后、黄昏、夜晚）、天气状态（大雨、晴朗、雷暴）、街区中文横幅、角色信用度与元宝/人民币余额（`¥`）。
  - **右上角委托卡片与小地图**：小地图方位改为 `北 / 东 / 南 / 西`；联络人改为“苏小小”、“白娘子”，展示中文委托目标与距离。
  - **左下角快捷栏与右下角车速表**：快捷键提示、操作指南卡片、委托日志抽屉（`[J]`）以及系统设置菜单（`[ESC]` 画面、镜头、音频、后处理四页签）全部转为自然流畅的中文。

## 3. 关键产品决策与技术权衡

- **决策 1：采用程序化 Canvas 2D 国潮绘图替代含日文的图片灯箱**
  - *方案*：在纹理图集构建阶段，使用 Canvas 2D 绘制带有传统印章、边框与中文字体的方形灯箱与街头海报，替代原有的日文切片贴图。
  - *原因*：确保 100% 消除残留日文，同时无需加载额外外部图片资源，零 404 风险且与 WebGPU 霓虹发光管线完美兼容。
- **决策 2：扩充中文字体回退栈并优化竖排标点旋转**
  - *方案*：将 Canvas 渲染器字体栈升级为跨平台中文字体（苹方/微软雅黑/思源黑体 + 楷体/宋体），并保留每个汉字独立分配闪烁通道（Segment ID）的机制。
  - *原因*：使汉字在近景下笔画锐利，且依然具备真实的单字霓虹灯管损坏闪烁效果。

### 核心状态与交互映射
- **街区触发器（Zones）**：当玩家在 3D 城市场景中移动时，坐标检测器实时匹配六大杭州特色街区（延安路霓虹大道、河坊古街灯笼巷、西子湖畔柳浪步道、拱宸映月桥、武林夜市街口、钱塘天际观景台），并在屏幕上方弹出对应的中文街区横幅。
- **委托任务闭环（Gigs）**：玩家抵达金色光柱目标点（如片儿川老面馆门前、西湖垂柳下、河坊古巷石阶顶、天际观景台升降梯、拱宸桥头）后，自动触发中文完成提示、发放赏金并解锁下一项江南暗网委托。
